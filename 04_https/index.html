HTTPS 확장 — ACM + remote_state

개요 — STEP 04 학습 내용

이론적 배경

같은 state에 없는 리소스는 aws_lb.app.arn처럼 직접 참조할 수 없습니다. Terraform은 자기 state에 기록된 것만 알기 때문에, 다른 단계가 만든 리소스의 ID는 ① remote_state로 읽거나 ② 변수로 직접 전달하거나 ③ data 소스로 태그 검색해야 합니다. 이 단계는 ①을 실습합니다 — 02에서 배운 "파일을 나누면 ID 전달이 필요하다"의 실제 사례입니다.

인증서는 DNS 검증을 씁니다 — ACM이 요구하는 CNAME 레코드를 Route53 존에 자동 생성하면 소유권이 증명되어 콘솔 클릭 없이 발급이 끝납니다.

학습 목표

  • terraform_remote_state로 다른 단계의 outputs를 읽어 참조한다
  • 기존 리소스를 수정하지 않고 규칙·리스너를 "부착"해 확장한다
  • ACM DNS 검증이 Route53과 함께 완전 자동화되는 흐름을 이해한다

핵심 내용

  • remote_state: backend = "local" + path = "../03_real/terraform.tfstate"
  • local.real로 outputs를 짧게 참조 — local.real.alb_arn 등
  • domain_enabled가 거짓이면 이 단계 리소스 전체가 count=0 (빈 plan)
  • 03의 SG·ALB를 건드리지 않고 aws_security_group_rule·aws_lb_listener로 확장

산출물 · 완료 기준

  • ACM 인증서 (app.<도메인>, DNS 검증)
  • Route53 검증 레코드 + 발급 완료 대기
  • ALB SG의 443 인바운드 규칙
  • ALB의 HTTPS 리스너 → 03의 타깃그룹
  • [ ] terraform plan이 remote_state를 읽고 5개 리소스 계획을 세움
  • [ ] apply 후 https://app.<도메인>으로 접속됨 (존 위임 완료 시)
  • [ ] terraform destroy 후에도 03의 ALB·존이 그대로 남아 있음
  • [ ] HTTP 리스너가 forward 그대로라 80 포트도 계속 열린다는 것을 설명할 수 있음 — 리다이렉트를 원하면 03의 리스너 코드를 바꿔야 함 (별도 state로는 못 바꿈)

실습 — STEP 04 실행

아래 명령은 터미널에서 프로젝트 루트(aws-tf/) 기준으로 실행합니다.

실행 방법

복사 버튼으로 명령을 가져간 뒤 터미널에 붙여넣기 (⌘V) 하세요.

cd 04_https

실습 단계

  1. cd ../03_real && terraform apply — 선행 인프라 (이미 올려둔 상태면 생략)
  2. cd ../04_https && terraform init && terraform apply
  3. terraform output https_url로 주소 확인 → 브라우저에서 접속
  4. Route53 콘솔에서 cert_validation 레코드가 자동 생성된 것 확인
  5. 정리: terraform destroy (인증서·리스너만 삭제, 03 인프라는 그대로)

소스 구조

파일·디렉터리 역할

  • main.tf의 data "terraform_remote_state": 03의 state 파일을 읽는 창구 — local.real.alb_arn처럼 outputs만 읽을 수 있음 (리소스 자체는 못 건드림)
  • aws_security_group_rule: 03이 만든 SG에 규칙만 추가 — SG 소유는 03, 규칙 소유는 04 (destroy 시 규칙만 사라짐)
  • aws_lb_listener.https: 03의 ALB에 리스너 부착 — 03의 80 리스너와 공존 (HTTP도 계속 동작)

04_https · STEP 04 학습 자료 
# ============================================================
# main.tf — 03_real 위에 HTTPS를 얹는 선택 단계
# 03이 만든 ALB·Route53 존을 terraform_remote_state로 읽어
# 인증서 발급 → 443 규칙 → HTTPS 리스너만 추가한다
# ============================================================

# remote_state — 03_real의 outputs를 읽는 data 소스
# 별도 state라 직접 참조(aws_lb.app.arn)가 불가 → outputs 경유
# 03_real이 apply 되어 있지 않으면 plan 단계에서 실패
data "terraform_remote_state" "real" {
  backend = "local"
  config = {
    path = var.real_state_path
  }
}

locals {
  # 03의 outputs를 짧은 이름으로 — 읽는 쪽 코드가 깔끔해짐
  real = data.terraform_remote_state.real.outputs

  # 도메인과 존이 둘 다 있어야 이 단계의 리소스가 의미가 있음
  # 비어 있으면 전부 count=0 — plan은 되지만 아무것도 안 만듦
  domain_enabled = var.domain_name != "" && local.real.route53_zone_id != ""
}


# ---------------- ACM 인증서 ----------------
# DNS 검증 — Route53에 검증 레코드를 자동 생성해 콘솔 작업 불필요

# ACM 인증서 — TLS 발급 (DNS 검증)
resource "aws_acm_certificate" "app" {
  count             = local.domain_enabled ? 1 : 0
  domain_name       = "app.${var.domain_name}"
  validation_method = "DNS"

  lifecycle {
    create_before_destroy = true # 재발급 시 새 인증서를 먼저 만들고 교체
  }
}

# 검증용 DNS 레코드 — 03의 Route53 존에 생성
resource "aws_route53_record" "cert_validation" {
  for_each = local.domain_enabled ? {
    for o in aws_acm_certificate.app[0].domain_validation_options : o.domain_name => o
  } : {}

  zone_id = local.real.route53_zone_id # 03의 존 — remote_state 출력 참조
  name    = each.value.resource_record_name
  type    = each.value.resource_record_type
  records = [each.value.resource_record_value]
  ttl     = 60
}

# 검증 대기 — 레코드 전파까지 apply가 블로킹 (수 분 소요 가능)
resource "aws_acm_certificate_validation" "app" {
  count                   = local.domain_enabled ? 1 : 0
  certificate_arn         = aws_acm_certificate.app[0].arn
  validation_record_fqdns = [for r in aws_route53_record.cert_validation : r.fqdn]
}


# ---------------- ALB에 443 연결 ----------------
# 03의 리소스를 수정하는 것이 아니라 "규칙·리스너"를 새 리소스로 부착
# → 03의 state를 건드리지 않고 확장하는 패턴

# SG 규칙 — 03의 ALB SG에 443 인바운드 추가
resource "aws_security_group_rule" "alb_https" {
  count             = local.domain_enabled ? 1 : 0
  type              = "ingress"
  security_group_id = local.real.alb_sg_id
  from_port         = 443
  to_port           = 443
  protocol          = "tcp"
  cidr_blocks       = ["0.0.0.0/0"]
  description       = "HTTPS"
}

# HTTPS 리스너 — 03의 ALB에 부착, 03의 타깃그룹으로 전달
resource "aws_lb_listener" "https" {
  count             = local.domain_enabled ? 1 : 0
  load_balancer_arn = local.real.alb_arn
  port              = 443
  protocol          = "HTTPS"
  ssl_policy        = "ELBSecurityPolicy-TLS13-1-2-2021-06"
  certificate_arn   = aws_acm_certificate_validation.app[0].certificate_arn

  default_action {
    type             = "forward"
    target_group_arn = local.real.alb_target_group_arn
  }
}

# ============================================================
# outputs.tf — apply 후 확인할 값
# ============================================================

output "certificate_arn" {
  description = "발급된 ACM 인증서 ARN"
  value       = local.domain_enabled ? aws_acm_certificate.app[0].arn : ""
}

output "https_url" {
  description = "HTTPS 접속 주소 — 인증서 검증·존 위임이 끝나야 열림"
  value       = local.domain_enabled ? "https://app.${var.domain_name}" : ""
}

# ============================================================
# providers.tf — provider + 공통 태그
# - default_tags: 여기 선언한 태그가 모든 리소스에 자동 적용
#   리소스별 tags와 병합되며, 리소스 태그가 같은 키면 우선
# ============================================================

provider "aws" {
  region = var.aws_region # Asia Pacific (Seoul)

  default_tags {
    tags = {
      Project = var.project_name
      Managed = "terraform"
    }
  }
}

# ============================================================
# variables.tf — 입력 변수
# 이 단계는 03_real이 먼저 apply 되어 있어야 동작합니다
# ============================================================

variable "aws_region" {
  description = "AWS 리전"
  type        = string
  default     = "ap-northeast-2"
}

variable "project_name" {
  description = "프로젝트 이름 — 태그·리소스 이름 접두사 (03_real과 동일해야)"
  type        = string
  default     = "terraform"
}

variable "domain_name" {
  description = "인증서를 발급할 도메인 — 03_real의 Route53 존과 같은 도메인이어야 함"
  type        = string
  default     = "jarrod.site"
}

variable "real_state_path" {
  description = "03_real의 terraform.tfstate 경로 — remote_state가 읽을 위치"
  type        = string
  default     = "../03_real/terraform.tfstate"
}

# ============================================================
# versions.tf — 코어·프로바이더 버전 고정
# - required_version: Terraform 실행 파일 버전 범위
# - required_providers: provider 소스·버전 — lock 파일과 쌍
# ============================================================

terraform {
  required_version = ">= 1.6"

  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 5.0"
    }
  }
}
